## Objective
This project demonstrates relational data acquisition and SQL analysis using pandas and SQLite. It creates customer, order, and JSON region sources; checks grain and key quality; validates joins using row counts and sales totals; and produces category, customer-segment, and regional KPIs.

## Key findings
1. Customer `C004` is a duplicate key; an uncleaned join multiplies order `O005` and overstates sales by KSh 9,100.
2. The cleaned join preserves 15 order rows and the KSh 113,500 source sales total; `C999` remains an unmatched order and must be investigated.
3. Corporate generated the highest segment sales at KSh 46,800, while Nairobi generated the highest regional sales at KSh 39,800.
